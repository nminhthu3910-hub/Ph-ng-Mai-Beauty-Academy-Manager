🔧 Kết nối Google Sheets

Dán URL Apps Script Web App của bạn vào đây để bắt đầu đồng bộ dữ liệu.

Chưa có URL? Làm theo các bước:
1. Mở Google Sheets mới → Extensions → Apps Script
2. Dán nội dung file spa_apps_script.gs vào
3. Chạy hàm setupSheets() để tạo cấu trúc
4. Deploy → New deployment → Web App → Anyone → Deploy
5. Copy URL → Dán vào ô trên → Lưu & Kết nối
